# skill-scout (스킬 감별사)

남이 만든 Claude 스킬을 찾고, 깔기 전에 세 가지를 판정하는 Claude Code 스킬이다: 믿을 만한가, 안전한가, 우리에게 맞는가. 쓰기로 하면 프로젝트에 맞게 고쳐서 하네스에 넣는 것까지 한다.

## 하는 일

1. **찾기**: 브라우저로 skillsmp.com을 검색해 후보를 5개 안으로 추린다. 카테고리를 고르게 하지 않고 검색으로 시작한다.
2. **출처 확인**: 사이트에 적힌 별 수를 믿지 않고 원본 GitHub 저장소를 `gh api`로 직접 조회한다.
3. **보안 점검**: 복제하거나 실행하지 않고 스킬 폴더의 모든 파일을 읽어 숨은 지시, 외부 전송, 자격 증명 읽기, 받아서 바로 실행, 본문 밖의 지시, 승인 넓히기, 과한 권한 등을 본다.
4. **적합성 판정**: 요청, 스택과 버전, 환경, 프로젝트 규칙과의 충돌, 이미 있는 스킬과의 중복을 본다.
5. **결과**: 스킬마다 짧은 설명, 출처, 보안, 적합성, 권고를 표로 돌려주고, 적합성을 무엇에 비춰 어떤 기준으로 봤는지 적는다.
6. **묻기**: 지금 적용할지, 어디에 둘지 사용자에게 묻는다.
7. **적용**: 승인받으면 검사한 커밋에 고정해 넣는다. 고쳐서 넣는 경우의 절차는 `apply.md`에 있다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `SKILL.md` | 찾기, 출처 확인, 보안 점검, 적합성 판정, 결과, 적용 여부 묻기 |
| `apply.md` | 프로젝트에 맞게 고쳐서 하네스(스킬, 에이전트 정의, 점검표)에 넣는 단계 |

## 필요한 것

- Claude Code와 브라우저 도구 (skillsmp.com은 일반 요청으로는 열리지 않는다)
- 로그인된 GitHub CLI(`gh`)

## 설치

이 저장소를 개인 스킬 폴더에 `skill-scout`라는 이름으로 둔다.

```bash
git clone https://github.com/dlsxody1/skill-scout.git ~/.claude/skills/skill-scout
```

## 쓰는 법

Claude Code에서 "쓸 만한 스킬 찾아줘", "이 스킬 깔아도 돼?", "찾은 스킬 우리 프로젝트에 맞게 고쳐서 넣어줘"처럼 말하거나, skillsmp나 GitHub의 SKILL.md 링크를 준다.

## 한계

읽어서 하는 점검은 보증이 아니다. 별 수는 살 수 있고, 검사한 뒤에 저장소가 바뀔 수 있다. 그래서 설치는 검사한 커밋에 고정하고 사람의 승인을 받는다.
